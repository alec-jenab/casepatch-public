Make a realistic synthetic copy of a document case

Add the files of one case: native or scanned PDFs, phone photos, ID images, and the agent's JSON, JSONL or text traces (transcripts, tool calls, expected outputs). CasePatch finds names, numbers, addresses, faces, signatures and codes, replaces them in place with consistent synthetic values across every file, keeps amounts and dates, and checks the result. You review every page before anything is exported.

    Analyzing your case…

    Reading text layers and pixels (OCR), finding sensitive values and visual regions, building one case-wide identity map, rendering fresh files and re-scanning them independently. Typical time: about 10 seconds per page on an 8-core laptop CPU; the first run loads local models.

            Usage & privacy

            Local usage counters, stored in ~/.casepatch/usage.sqlite on this computer and never sent. They hold per-day numbers only (cases, documents, pages, re-renders, exports, processing seconds): no file names, text, values or paths. Reset counters empties them; deleting the file is also fine. Set CASEPATCH_HOME to keep this folder elsewhere.

            Anonymous usage events

            Off by default. If you opt in, CasePatch records events like “case analyzed: 6 pages” or “reviewed export completed” with a random install id — never file names, document text, values or paths. They are kept in ~/.casepatch/events.jsonl. This build cannot send them anywhere: sending needs a telemetry endpoint the project has not enabled yet.

            How CasePatch works
            
  
            1. Add the files of one case. Files are processed together so one person gets one synthetic identity in every file.
              2. 
  
            2. Analyze: text layers and OCR, rules-based detection with case-wide propagation, face/signature/QR/barcode detection.
              3. 
  
            3. Review: compare before/after for every page. Keep values that are not sensitive, add values that were missed, choose what happens to each face, signature or code, then re-render. When several editors are available, pick one per change (or use one editor for all); boxes mark every change on the full page.
              4. 
  
            4. Export: you must open every output page and confirm before downloading.
            
  
            Amounts, dates and other facts are kept unless you select them. Text is redrawn in the document's own font on native PDFs; scans and photos are inpainted and redrawn to match. Faces, signatures and codes are replaced with synthetic ones.
            
  
            Agent mode (optional, off by default): after analysis, an AI agent can make the edits with CasePatch's tools and checks, using your own Anthropic key, for one case at a time, after you accept a notice. You then keep or undo each agent edit, and every flagged item needs your decision before export.
            
  
            Limits: early alpha. Detection can miss data; handwriting other than signatures is not detected; replaced text on low-quality scans can look cleaner than the original. Not a HIPAA/PCI de-identification tool.
